React, Vite, Tailwind CSS

## Features

- Dark mode
- Quick setup

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/le-sultan-spa.git
cd le-sultan-spa
npm install
npm run dev
```
Open http://localhost:5173. Build for production with `npm run build`.
